# ClearExam

A restyled copy of the exam booking project. Same features, new look and names.

## Run

```bash
cd ~/Desktop/exam-hub-replica
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python app.py
```

Open http://127.0.0.1:5000
